## Hola 👋 <!-- cambia esto por: Hola, soy TU NOMBRE -->

Automatizo **tareas repetitivas con Excel y Python** para negocios: reportes que se arman solos, limpieza y unificación de datos, y procesos que hoy alguien hace a mano cada semana.

### 🛠️ Qué puedo hacer por tu negocio
- Unir archivos de ventas, inventario o cartera de varias sucursales en **un solo reporte de Excel con gráficos**
- **Limpiar datos** desordenados: fechas y precios en distintos formatos, duplicados, errores de digitación
- Enviar reportes **automáticamente por correo** cada semana o cada mes
- Leer datos desde **Google Sheets** o desde la exportación de tu software de facturación

### 📂 Proyecto destacado
**[Reporte de ventas automático](https://github.com/Samu607/reporte-ventas-automatico)**: convierte los CSV y Excel desordenados de cada sucursal en un reporte con resumen, rankings de productos y vendedores, y una lista de filas con errores. Todo con un solo comando.
